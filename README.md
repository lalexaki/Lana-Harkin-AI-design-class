# Lana Harkin — AI for Interdisciplinary Design Portfolio

A static, three-page portfolio built from Lana's supplied project materials.

- `index.html`: interactive raccoon playground and project links
- `album-cover.html`: AM cover study, final artwork and selected process
- `clearspan.html`: gymnastics center, concept comparison and Blender video
- `assets/`: optimized images, original process PDFs and supplied MP4

No installation or build is required. For local preview, run `python3 -m http.server 8765` in this folder.

## Publishing

Destination: `lalexaki/Lana-Harkin-AI-design-class`.
Enable GitHub Pages using the `main` branch and `/ (root)` folder.
Expected URL: https://lalexaki.github.io/Lana-Harkin-AI-design-class/

All site links and assets use relative paths, so they work under the repository path.

## Interaction

Click or tap the drawing area to add one cute raccoon at the pointer. Successive raccoons vary in pastel color, size, and rotation, cycling through heart-holders, sleepy royals, and waving bow-tied buddies. Enter or Space adds a raccoon while the area is focused. Undo removes the newest raccoon; Clear canvas removes all raccoons. The most recent 40 raccoons are retained until page reload. On a touch screen, vertical scrolling remains available. Artwork may be cropped at the canvas edge by design.

## Project material

The album artwork was extracted from the final-result area of the supplied PDF, preserving its typography and proportions. The gym's final AI concept image is labeled separately from the supplied Blender video. The 30-second silent MP4 is 640 × 360. PDFs are copies of the supplied originals.

This is classroom work. The AM cover is an unofficial study; original artwork credits and sources appear on the project page and in the process PDF. Clearspan is a fictional future-space concept, with unvalidated planning assumptions noted on its page.
