# Cosmic Daydreamer — Week 1 proposal

This editable proposal webpage is linked as project 03 under Selected projects on Lana Harkin’s GitHub Pages portfolio. It is a published draft: firsthand gameplay observations, the final personal reflection, and original image credits are still pending. Publication does not submit the assignment to Canvas.

## Open it

Open `index.html` in a browser. Keep `styles.css`, `app.js`, and the `assets` folder beside it. No package installation or build is needed. If using the ZIP, extract the entire folder first.

The storyboard buttons preview the proposed opening, three stages, and ending. They are a presentation interaction, not the finished game. The sound sketch plays only when selected.

## What is drafted

- Title, original concept illustration, premise, and intended player experience.
- An opening, three short stages, five fragments, an ending, a five-frame storyboard, and a flowchart.
- One main click/tap interaction, with movement and keyboard alternatives specified for the future game.
- Your actual AI discussion: surprise may not always feel relaxing, and players differ in how much unpredictability they enjoy.
- Design responses: repeatable events, persistent rewards, gentle cues, and optional Gentle guidance.
- Annotated mood board using your five inspiration images, palette, typography, motion, interface, and sound direction.
- Week 2 implementation plan and Week 3 playtest/refinement plan.
- Linked research and an explicit authorship register.
