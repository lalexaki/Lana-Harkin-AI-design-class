# Cosmic Daydreamer — Week 1 game proposal

A complete proposal webpage for Lana Harkin’s Hallucination project, linked as project 03 under Selected projects on her class portfolio.

Public proposal: https://lalexaki.github.io/Lana-Harkin-AI-design-class/cosmic-daydreamer/

## Content

- Game introduction, original concept illustration, narrative, and interpretation of Hallucination.
- Sandspiel browser-edition case study: played October 25, 2026, with three meaningful moments, two supplied gameplay screenshots, and five action → response → understanding events.
- Creator research, personal observation, and interpretation distinguished explicitly.
- Two student-identified gaps in the AI analysis, a selected exchange, and the student’s conclusion connecting exploration with structure.
- Opening, three short stages, ending, five-frame storyboard, and flowchart.
- Annotated visual references, typography, color, interface, motion, and sound guide.
- Week 2 prototype and Week 3 playtesting/refinement plan.
- Sources and authorship register.

The former editable worksheets have been replaced with static, readable case-study content. Visitors now see the completed answers without relying on browser storage. The code does not delete any notes previously saved by the old worksheet.

## Implementation

Static HTML, CSS, and JavaScript; no build step or external package dependencies. Keep the assets folder beside index.html. The storyboard is a proposal preview, not the completed game. The sound cue is opt-in; dreamy lo-fi music and environmental audio are planned for the Week 2 prototype.

Publication is separate from Canvas submission. Submit the direct proposal URL through the assignment’s Website URL option.
